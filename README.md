## 📖 프로젝트 개요

**미니왕국**은 로그라이크 던전 탐험과 왕국 건설을 결합한 캐주얼 모바일 게임입니다.  
플레이어는 왕으로서 직접 던전에 뛰어들어 자원을 수집하고, 수집한 자원으로 왕국을 건설합니다.  
건설된 왕국 시설과 도감(발견의 서)은 다음 던전 런에 영구적인 스탯 보너스를 주어, **탐험과 건설이 선순환하는 게임 루프**를 제공합니다.  
특히 에너지 제한이 없어 무제한으로 플레이할 수 있으며, 일일 보너스와 왕의 칙령 시스템으로 매일 새로운 재미를 선사합니다.

## 🎯 핵심 특징 (Key Features)

| 시스템 | 설명 |
|------|------|
| **무제한 플레이 & 일일 보너스** | 에너지(티켓) 제한 없이 언제든 플레이 가능! 첫 5회 런은 1.5배 보상 지급 |
| **왕의 칙령** | 매일 3가지 칙령 중 하나를 선택해 하루 종일 지속되는 버프 적용 |
| **왕국 방어 이벤트** | 매주 수요일, 플레이어가 건설한 시설과 주민의 힘으로 몰려오는 몬스터를 자동 방어 |
| **발견의 서 (도감)** | 몬스터, 아이템, 시설을 수집해 기록하고 영구적인 스탯 보너스를 획득 |
| **완벽 회피 (Perfect Dodge)** | 찰나의 순간에 적의 공격을 피하면 발동하는 슬로모션 + 2배 타격 효과 |
| **친구 왕국 방문** | 복잡한 길드 대신 도입된 가벼운 소셜. 친구 왕국에서 영감 버프 획득 |
