## 1. UX 설계 철학

### 1.1 핵심 원칙

| 원칙 | 설명 | 예시 |
|------|------|------|
| **한 손 조작** | 세로 모드, 엄지 하나로 모든 조작 | 하단에 주요 버튼 배치 |
| **3초 규칙** | 어떤 화면이든 3초 내에 이해 가능 | 직관적 아이콘, 최소한의 텍스트 |
| **즉각 피드백** | 모든 터치에 시각/청각/진동 반응 | 버튼 스케일 애니메이션, 효과음 |
| **최소 학습 비용** | 튜토리얼 없이도 플레이 가능 | 점진적 기능 해금 |
| **즐거운 연출** | 보상, 레벨업, 건설에 과한 연출 | 금화 분수, 불꽃놀이, 팡파레 |

### 1.2 터치 영역

```
┌──────────────────────────┐
│                          │
│    ┌──────────────┐      │
│    │              │      │  ← 시각 정보 영역
│    │   게임 화면   │      │     (보기만 하는 곳)
│    │              │      │
│    │              │      │
│    └──────────────┘      │
│                          │
│  ┌──────────────────┐    │  ← 인터랙션 영역
│  │   터치 조작 영역   │    │     (엄지가 닿는 곳)
│  │  버튼/스킬/메뉴   │    │
│  └──────────────────┘    │
└──────────────────────────┘
```

**터치 타겟 최소 크기: 44×44dp (iOS HIG 기준)**


## 4. 인터랙션 디자인

### 4.1 제스처 맵

| 제스처 | 왕국 화면 | 전투 화면 |
|--------|-----------|-----------|
| **탭** | 시설 선택 | 스킬 발동 |
| **드래그** | 화면 이동 | 회피 (스와이프) |
| **롱프레스** | 시설 정보 | 스킬 정보 |
| **핀치** | 줌 인/아웃 | - |
| **더블탭** | 시설 퀵메뉴 | - |

### 4.2 피드백 시스템

모든 인터랙션에 **3중 피드백** 적용:

```
터치 → 시각 (스케일 바운스 0.9→1.0)
     → 청각 (버튼 효과음)
     → 촉각 (약한 진동, 선택적)
```

## 5. 온보딩 & 튜토리얼

### 5.1 점진적 해금 (Progressive Disclosure)

```
첫 플레이 → 첫 던전 자동 진입 (기본 조작 학습)
         → 왕국 귀환 (첫 시설 건설 안내)
         → 두 번째 던전 (레벨업 선택 학습)
         → 왕국 (발견의 서 도감 및 왕의 칙령 해금)
         → 자유 플레이!
```

### 5.2 튜토리얼 원칙

- ❌ **긴 텍스트 설명 없음**
- ✅ **실제 플레이하면서 학습** (Learn by doing)
- ✅ **스킵 가능** (경험자 배려)

## 8. 사운드 디자인 (Sound Design)

### 8.1 BGM (배경음악)
- **왕국 (허브)**: 경쾌하고 평화로운 중세풍 음악 (건설의 즐거움)
- **던전 (탐험)**: 긴장감은 있지만 너무 무겁지 않고 귀여운 탐험 음악
- **보스전**: 열정적이고 빠른 템포의 전투 음악
- *참고 레퍼런스*: Stardew Valley, Moonlighter 사운드 트랙

### 8.2 SFX (효과음)
- **전체적인 톤**: 통통 튀는 느낌, 캐주얼하고 과장된 효과음
- **UI 조작음**: 맑고 긍정적인 실로폰/목관악기 소리
- **몬스터 타격**: '퍽', '팡' 등 묵직하면서도 코믹한 타격감
- **완벽 회피**: 날카롭지만 시원한 '챙!' 소리와 함께 공간감이 느껴지는 사운드

## 9. 알림 & 리텐션 UX

### 9.1 인게임 알림

```
건설 완료 → 왕국 화면에 ❗ 배지
왕의 칙령 미선택 → 상단 바에 ❗ 배지
새 도감 등록 → 도감 탭에 N 배지
```

### 9.2 푸시 알림 (절제)

| 알림 | 타이밍 | 빈도 |
|------|--------|------|
| 일일 보너스 리셋 | 매일 오전 5시 직후 | 하루 1회 |
| 건설 완료 | 건설 완료 시 | 이벤트성 |
| 왕국 방어 이벤트 | 수요일 오후 | 주 1회 |

**원칙: 에너지가 없으므로 재접속 압박을 줄이고 보상/이벤트 위주의 알림 구성**
