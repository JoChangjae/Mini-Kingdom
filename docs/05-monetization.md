# 💰 수익화 전략

> **미니왕국의 F2P 수익 모델 — 무제한 플레이를 보장하는 유저 친화적 수익화**

---

## 1. 수익화 철학

### 1.1 핵심 원칙

> **"무제한 플레이를 보장하되, 가치 있는 패스와 꾸미기를 제공한다"**

| 원칙 | 설명 |
|------|------|
| **No Energy System** | 답답한 에너지/티켓 제한 없이 무제한 플레이 보장 |
| **Pay-to-Skip, Not Pay-to-Win** | 과금은 시간 단축과 외형, 편의성 중심 |
| **공정한 경쟁** | 랭킹은 실력 기반, 과금 장비 별도 리그 |
| **가치 있는 과금** | 과금이 실질적 편의/즐거움 제공 |
| **압박 없는 제안** | 팝업 최소화, 유저가 찾아가는 상점 |

### 1.2 수익원 비중 목표

```

스킨/꾸미기  ████████                15%
광고 (선택)  █████                   10%
```

## 2. 화폐 구조

### 2.1 화폐 종류

```
┌──────────────────────────────────────────────┐
│                                              │
│  💰 금화 (소프트 화폐)                         │
│  ├── 획득: 던전 보상, 퀘스트, 자동 생산        │
│  └── 용도: 건설, 강화, 상점 구매               │
│                                              │
│  👑 왕관 (프리미엄 화폐)                       │
│  ├── 획득: 과금, 업적, 배틀패스, 일일 보상     │
│  └── 용도: 편의 기능, 스킨, 즉시 건설          │
│                                              │
└──────────────────────────────────────────────┘
```

### 2.2 무과금 일일 수급량

| 화폐 | 일일 획득 | 주요 출처 |
|------|-----------|-----------|
| 💰 금화 | ~1500+ | 무제한 던전 플레이 + 일일퀘스트 + 자동생산 |
| 👑 왕관 | ~30 | 일일 보상 + 업적 + 광고 |

| 상품 | 왕관 | 원화 환산 |
|------|------|-----------|
| 즉시 건설 (1시간 단축) | 10 | ~₩330 |
| 일일 보너스 추가 (1회) | 30 | ~₩1,000 |
| 프리미엄 장비 상자 | 80 | ~₩2,600 |
| 코스튬 스킨 1개 | 150 | ~₩5,000 |

## 3. 배틀패스 (핵심 수익원)

### 3.1 구조

```
무료 트랙:  ── 🎁 ── 🎁 ── 🎁 ── 🎁 ── 🎁 ── ... ── 🎁 (Lv.50)
프리미엄:   ── 🎁 ── 🎁 ── 🎁 ── 🎁 ── 🎁 ── ... ── 👑 (Lv.50)
                                                    전설 스킨
```

| 항목 | 내용 |
|------|------|
| **시즌 주기** | 4주 (1달) |
| **가격** | ₩5,900 (프리미엄) / ₩12,900 (프리미엄+) |
| **최대 레벨** | 50 |
| **레벨업 방법** | 일일/주간 미션 완료, 던전 클리어 |
| **프리미엄+ 혜택** | 10레벨 선행 해금 + 전용 프레임 |

### 3.2 보상 예시 (시즌 1)

| 레벨 | 무료 보상 | 프리미엄 보상 |
|------|-----------|---------------|
| 1 | 💰 100 | 👑 50 |
| 5 | 🪵 50 | 🎨 "봄" 왕관 스킨 |
| 10 | 📦 일반 장비상자 | 📦 희귀 장비상자 |
| 15 | 💰 300 | 🏠 "꽃집" 장식 건물 |
| 20 | ⚙️ 20 | 👑 100 |
| 25 | ⚙️ 50 | 🎨 "기사왕" 캐릭터 스킨 |
| 30 | 💰 500 | 📦 영웅 장비상자 |
| 35 | 🌿 100 | 🐾 "고양이" 펫 |
| 40 | 📦 희귀 장비상자 | 👑 200 |
| 45 | 💰 1000 | 🎨 특수 이펙트 |
| **50** | 📦 영웅 장비상자 | 🎨 **전설 "황금왕" 스킨** |

### 3.3 배틀패스 밸런스

- **무과금도 매력적인 무료 트랙**: 자원, 장비상자 제공
- **프리미엄 = 외형 + 편의**: 전투력 차이 최소화
- **4주 안에 Lv.50 도달 가능**: 꾸준한 무제한 플레이 + 미션 수행 시
- **시즌 테마**: 봄/여름/가을/겨울 or 해적/마법/동양/서부

## 5. 광고 수익화 (비침투적)

### 5.1 광고 원칙

- ❌ 강제 광고 **절대 없음**
- ✅ 모든 광고는 **유저가 자발적으로 시청**
- ✅ 광고 시청 시 **명확한 보상** 제공
- ✅ 하루 **최대 5~10회** 제한 (피로도 방지)

### 5.2 보상형 광고 (Rewarded Video)

| 위치 | 보상 | 일일 제한 |
|------|------|-----------|
| 던전 결과 — 보상 2배 | 획득 자원 ×2 | 3회 |
| 부활 — 한번 더 도전 | HP 50% 회복 후 계속 | 1회/런 |
| 무료 상자 — 일일 보상 | 일반 장비상자 1개 | 1회 |
| 건설 시간 단축 | 30분 단축 | 3회 |

|--------|--------|------|
| 배틀패스 | \$0.04 | 월 \$5.9 × 전환율 20% ÷ 30일 |
| IAP | \$0.025 | 왕실 보급품 등 패키지 구매 |
| 스킨 | \$0.012 | 비정기 구매 및 커스터마이징 |

| **합계** | **\$0.085** | 배틀패스 중심의 안정적 구조 |
