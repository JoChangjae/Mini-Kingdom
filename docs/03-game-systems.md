## 1. 전투 시스템 상세

### 1.1 캐릭터 스탯

| 스탯 | 약어 | 설명 | 기본값 |
|------|------|------|--------|
| 체력 | HP | 0이 되면 런 종료 | 100 |
| 공격력 | ATK | 기본 공격 데미지 | 10 |
| 방어력 | DEF | 받는 데미지 감소 | 5 |
| 공격 속도 | SPD | 초당 공격 횟수 | 1.0 |
| 치명타율 | CRT | 치명타 확률 (%) | 5% |
| 치명타 피해 | CDMG | 치명타 배율 | 150% |
| 이동 속도 | MOV | 이동 속도 | 3.0 |
| 회피율 | EVD | 공격 회피 확률 | 0% |

### 1.2 데미지 공식

```
기본 데미지 = ATK × 스킬_배율
방어 적용  = 기본 데미지 × (100 / (100 + 적_DEF))
최종 데미지 = 방어 적용 × 약점_보정 × 치명타_배율 × (0.9 ~ 1.1 랜덤)
```

### 1.3 무기 타입

| 무기 | 사거리 | 공격 방식 | 특징 |
|------|--------|-----------|------|
| ⚔️ **검** | 근접 | 넓은 범위 휘두르기 | 밸런스형 |
| 🗡️ **단검** | 근접 | 빠른 연속 공격 | 고속, 저데미지 |
| 🪓 **도끼** | 근접 | 느린 강타 | 고데미지, 저속 |
| 🏹 **활** | 원거리 | 직선 발사 | 안전한 원거리 |
| 🪄 **지팡이** | 원거리 | 유도탄 발사 | 마법 데미지 |
| 🛡️ **방패+검** | 근접 | 공격+방어 | 방어 특화 |

### 1.4 스킬 시스템

**스킬 슬롯: 2~3개** (마법탑 레벨에 따라)

스킬 구조:
```
[스킬명]
├── 타입: 공격 / 방어 / 버프 / 소환
├── 쿨타임: 5~30초
├── 데미지/효과: 수치
├── 범위: 단일 / 범위 / 전체
└── 연출: 이펙트 + 카메라 쉐이크
```

**스킬 예시:**

| 스킬 | 타입 | 쿨타임 | 효과 |
|------|------|--------|------|
| 🔥 왕의 분노 | 공격 | 15초 | 전방 부채꼴 ATK×300% 피해 |
| 🛡️ 왕실 방벽 | 방어 | 20초 | 3초간 데미지 80% 감소 |
| ⚡ 천둥 소환 | 공격 | 25초 | 랜덤 3곳에 낙뢰 ATK×200% |
| 💚 왕의 만찬 | 회복 | 30초 | HP 30% 회복 |
| 👥 근위대 소환 | 소환 | 30초 | NPC 2명 10초간 전투 보조 |

### 1.5 회피 및 완벽 회피 (Perfect Dodge)

- **기본 회피**: 스와이프로 구르기 (일시적 무적 프레임)
- **완벽 회피**: 적 공격 직전 타이밍에 회피 성공 시 발동
  - **효과**: 0.5초 슬로모션 + 다음 공격 데미지 2배 적용
  - **시각 효과**: 화면 가장자리가 금빛으로 번쩍임
  - 캐주얼 게임 속에서도 숙련도를 보상하는 핵심 컨트롤 요소

### 1.6 데미지 타입 및 상성 시스템 (간소화)

기존 4원소에서 **3타입(물리 / 마법 / 자연)**으로 간소화. 복잡한 꼬리물기 상성을 제거하고 몬스터별 약점/저항 시스템을 도입합니다.

- **물리 (Physical)**: 검, 도끼, 화살 등 물리적 타격
- **마법 (Magic)**: 지팡이, 마법 스킬 데미지
- **자연 (Nature)**: 독, 덩굴, 속성 피해 등

**몬스터 약점/저항 예시:**
- 🪨 골렘: **물리 저항** (데미지 -50%), **마법 약점** (데미지 +50%)
- 👻 정령: **마법 저항** (데미지 -50%), **물리 약점** (데미지 +50%)
- 💦 슬라임: **자연 저항** (데미지 -50%), **물리 약점** (데미지 +50%)

## 2. 레벨업 & 빌드 시스템

### 2.1 런 내 레벨업

- 몬스터 처치 시 경험치 획득
- 레벨업 시 3가지 옵션 중 1개 선택
- **최대 레벨: 15** (런 당)

### 2.2 업그레이드 풀 (Pool)

업그레이드는 **티어**로 구분되며, 레벨에 따라 상위 티어 등장:

| 티어 | 등장 레벨 | 색상 | 예시 |
|------|-----------|------|------|
| Common | Lv.1+ | ⬜ 흰색 | 공격력+5%, HP+10 |
| Uncommon | Lv.3+ | 🟩 초록 | 관통 공격, 넉백 추가 |
| Rare | Lv.6+ | 🟦 파랑 | 연쇄 번개, 흡혈 공격 |
| Epic | Lv.9+ | 🟪 보라 | 분신 소환, 시간 정지 |
| Legendary | Lv.12+ | 🟨 금색 | 궁극기 해금, 변신 |

### 2.3 시너지 시스템

같은 카테고리의 업그레이드를 3개 이상 선택하면 **시너지 보너스** 발동:

```
⚔️ 공격 ×3 선택 → "광전사" 시너지: 공격력 +30%, 받는 피해 +10%
🛡️ 방어 ×3 선택 → "철벽" 시너지: 방어력 +40%, 이동속도 -10%
⚡ 속도 ×3 선택 → "질풍" 시너지: 공격/이동 속도 +50%
🔮 마법 ×3 선택 → "대마법사" 시너지: 스킬 쿨타임 -40%
```

### 2.4 스킬 융합 (Skill Fusion) 상세

2개의 특정 스킬을 각각 최대 레벨(Lv.5)까지 달성하면, 다음 레벨업 시 **융합 스킬(Ultimate)** 선택지가 등장합니다.
- **공식/조건**: `스킬A(Lv.MAX) + 스킬B(Lv.MAX) = 융합 스킬C`
- **특징**: 기존 스킬 슬롯 2개를 차지하지 않고 1개로 합쳐지며, 위력은 기존 두 스킬 합보다 강력합니다. 빈 슬롯에는 새로운 스킬을 배울 수 있습니다.
- **예시 조합**:
  - `화염구(Max)` + `회전 베기(Max)` = **🔥 화염 토네이도** (이동하면서 주변에 지속적인 화염 및 물리 피해)
  - `낙뢰(Max)` + `독 화살(Max)` = **⚡ 부식성 뇌우** (넓은 범위에 방어력을 깎는 독성 번개 피해)
  - `얼음 방패(Max)` + `치유의 빛(Max)` = **❄️ 서리의 성역** (무적 효과와 함께 초당 HP 회복 및 주변 적 빙결)

### 2.5 유물 시스템 (Relic System) 상세

유물은 런(Run) 중에만 유지되는 **패시브 아이템**입니다. 보스전 승리 또는 보물방에서 획득합니다.
- **일반 유물**: 소폭의 스탯 증가 (예: "전사의 장갑" - 공격력 +10%)
- **에픽 유물**: 특수한 조건부 능력 발동 (예: "흡혈귀의 이빨" - 적 처치 시 5% 확률로 HP 1 회복)
- **저주받은 유물 (하이 리스크 하이 리턴)**:
  - "악마의 계약서": 획득 골드 +200%, 최대 체력 -50%
  - "유리 대포": 공격력 +150%, 받는 피해 +100%

### 3.3 보스 패턴 설계

보스는 **페이즈 시스템** 사용:

```
보스 HP 100% ──→ 페이즈 1 (기본 패턴)
                  │ 패턴: 근접 공격 → 원거리 공격 → 돌진
                  │
보스 HP  50% ──→ 페이즈 2 (강화 패턴)
                  │ 패턴: 광역 공격 추가, 속도 증가
                  │ 연출: 분노 이펙트, 필드 변화
                  │
보스 HP  20% ──→ 페이즈 3 (최종 패턴)
                  │ 패턴: 궁극기 사용, 미니언 소환
                  │ 연출: BGM 변경, 화면 흔들림
```

## 5. 절차적 던전 생성

### 5.1 방 배치 알고리즘

```python
# 의사코드
def generate_dungeon(dungeon_config):
    rooms = []
    
    # 1. 방 개수 결정 (10~15)
    room_count = random(config.min_rooms, config.max_rooms)
    
    # 2. 고정 방 배치
    rooms[0] = ENTRANCE
    rooms[-1] = BOSS
    rooms[room_count // 2] = REST_OR_SHOP  # 중간에 휴식
    
    # 3. 나머지 방 채우기 (가중 랜덤)
    for i in remaining_slots:
        room_type = weighted_random({
            COMBAT: 50,
            EVENT: 15,
            ELITE: 10,
            SHOP: 10,
            TREASURE: 5
        })
        rooms[i] = room_type
    
    # 4. 난이도 곡선 적용
    apply_difficulty_curve(rooms)  # 후반부에 강한 적 배치
    
    # 5. 갈림길 추가 (30% 확률)
    add_branch_paths(rooms)
    
    return rooms
```

### 5.2 난이도 곡선

```
난이도
  ▲
  │         ╱╲        ╱╲
  │    ╱╲  ╱  ╲  ╱╲  ╱  ╲    ★ 보스
  │   ╱  ╲╱    ╲╱  ╲╱    ╲  ╱
  │  ╱                     ╲╱
  │ ╱    ↑휴식방              ↑ 보스 직전 휴식
  └──────────────────────────────→ 진행도
   입구                          보스
```

- **초반**: 쉬운 적으로 워밍업
- **중반**: 난이도 상승 + 중간 휴식
- **후반**: 높은 난이도 + 보스 전 마지막 휴식
- **보스**: 최고 난이도

### 5.3 방 내부 생성

각 방은 **템플릿 기반 + 랜덤 변형**:

```

│ #         #    │  . = 바닥
│      ...   #   │  T = 보물
│   ....T....    │  S = 스폰 포인트
│   .........    │  E = 입구
│   ....S....    │  X = 출구
│   .........    │
│ #         #    │
│ ####  E  ####  │
│ ####  X  ####  │
└────────────────┘
```

### 6.2 보상 배율 (일일 보너스 및 왕국 효과 적용)

```
최종 보상 = 기본 보상 × 일일_보너스_배율 × (1 + 왕국_보너스) × (1 + 던전_배율) × (1 + 칙령_배율)

예시 (일일 5런 이내 1.5배, 상인의 날 칙령 1.5배, 시장Lv.3 적용 시):
금화 100 × 1.5(일일 보너스) × (1 + 시장 0.15) × 1.5(상인의 날)
= 100 × 1.5 × 1.15 × 1.5
= 258 금화
```

## 7. 주민 시스템

### 7.1 주민 역할

왕국 레벨 5에서 해금. 주민을 시설에 배치하면 보너스 효과를 주며, 왕국 방어 이벤트 시 방어력에 기여합니다:

| 주민 직업 | 배치 시설 | 효과 | 왕국 방어 기여 |
|-----------|-----------|------|----------------|
| 👨‍🔧 대장장이 | 대장간 | 제작 속도 +20% | 중간 기여 |
| 🧙 마법사 | 마법탑 | 마법 연구 속도 +20% | 마법 방어 기여 |
| 👨‍🌾 농부 | 농장 | 식량 생산 +30% | 소규모 기여 |
| 💂 병사 | 훈련소 | 호위병 전투력 +15% | **높은 기여** |
| 🧑‍💼 상인 | 시장 | 거래 가격 +10% 유리 | 재정 복구 기여 |

### 7.2 주민 획득

- 던전에서 구출 (이벤트 방)
- 주점 건설 후 자동 유입
- 특수 이벤트/퀘스트 보상

### 7.3 방치형 세금 징수 (Offline Tax System)

오프라인 상태일 때도 주민들이 자원을 수집하여 **세금(Tax)** 형태로 보관합니다.
- **최대 누적 시간**: 12시간 (초기화 또는 확장 업그레이드 가능)
- **징수 공식**:
  - `분당 골드 생산량 = (왕국 레벨 × 2) + (전체 주민 수 × 1.5)`
  - `분당 기본 자원 생산량 = (해당 자원 관련 시설 레벨) × 0.5`
- **수령 방식**: 왕국 메인 화면의 **[국고(Treasury)]** UI에서 탭하여 수령.
- 주민 행복도가 높으면 오프라인 생산 효율에 최대 +20% 보너스가 붙습니다.

## 8. 발견의 서 (도감 시스템)

### 8.1 도감 구조

게임 내 콘텐츠를 수집하고 기록하는 백과사전 시스템.

- **몬스터 도감**: 처치한 몬스터 기록 (약점/저항 정보 확인 가능)
- **아이템/장비 도감**: 획득한 장비와 재료 기록
- **시설/NPC 도감**: 만난 NPC와 건설한 시설 정보 기록

### 8.2 수집 보상

도감 진척도 달성 시 **영구 스탯 보너스** 획득:
- 몬스터 10종 기록: 기본 공격력 +2%
- 장비 20종 수집: 기본 체력 +5%
- 도감 100% 달성 목표를 통한 장기 리텐션 유도.

## 9. 일일/주간/소셜 콘텐츠

### 9.1 일일 보너스 및 왕의 칙령 (에너지 대체 모델)

- **무제한 플레이**: 에너지(티켓) 시스템이 없어 언제든 원하는 만큼 플레이 가능합니다.
- **일일 보너스**: 매일 첫 5회 런은 획득 보상이 1.5배로 적용됩니다 (매일 오전 5시 리셋).
- **왕의 칙령 (일일 버프)**: 
  - 매일 3가지 칙령 중 1개 선택 가능. 
  - 예: '목재의 날'(목재 2배), '전사의 날'(공격력+20%), '상인의 날'(골드 1.5배). 
  - 하루 종일 지속되며, 일일 전략적 선택의 재미를 줍니다.

### 9.2 왕국 방어 이벤트 (주 1회, 수요일)

- 매주 수요일, 몬스터 무리가 왕국을 공격하는 이벤트가 발생합니다.
- 유저가 직접 전투하는 것이 아닌, 현재 **건설된 시설 수준과 배치된 주민들의 스탯**을 기반으로 방어력이 자동 계산되어 결과가 정해집니다.
- **방어 성공**: 대량의 보상 (보석, 희귀 재료 등) 획득.
- **방어 실패**: 시설 수리비 명목으로 보유 자원의 일부 소폭 감소 (큰 스트레스 방지).
- 왕국 발전을 지속해야 하는 강력한 메타 동기부여 요소입니다.

### 9.3 친구 왕국 방문

- 복잡한 길드 시스템을 제거하고 대체된 가벼운 소셜 활동입니다.
- 친구로 등록된 다른 플레이어의 왕국을 하루 최대 3회 방문할 수 있습니다.
- 방문 시 **'영감' 버프**를 획득하여 랜덤 소량의 자원이나 스탯 보너스를 받습니다.

## 10. 무작위 날씨 시스템 (Random Weather System)

매일(현실 시간 자정 기준) 무작위로 왕국과 던전의 날씨가 변경됩니다. 날씨는 게임의 비주얼뿐만 아니라 전투 공식에도 직접적인 영향을 줍니다.

### 10.1 날씨 효과

| 날씨 | 왕국 비주얼 | 던전/전투 메커니즘 (버프 & 디버프) |
|------|-----------|----------------------------------|
| ☀️ **맑음** | 화창하고 밝은 톤 | 기본 상태. 변화 없음. |
| 🌧️ **비** | 비가 내리며 바닥에 웅덩이 | **⚡번개 마법 피해 +20%**, **🔥화염 마법 피해 -20%**. |
| ❄️ **눈** | 눈보라와 눈 쌓인 지형 | 모든 캐릭터(적 포함) **이동 속도(MOV) -15%**. 빙결(Freeze) 상태이상 지속시간 +1초. |
| 🌫️ **안개** | 짙은 안개로 시야가 좁아짐 | 모든 캐릭터(적 포함) **회피율(EVD) +15%**. 원거리 공격 사거리 감소. |

## 11. 휴식방 낚시 미니게임 (Fishing Minigame)

던전 탐험 중 만나는 **휴식방**에서 단순한 회복/강화 외에 낚시를 즐길 수 있습니다.

### 11.1 미니게임 메커니즘
1. 휴식방의 물가 낚시터와 상호작용합니다.
2. 찌가 물에 잠기고 느낌표(!)가 뜨는 순간 **타이밍에 맞춰 화면을 탭**합니다.
3. 탭한 타이밍(Perfect / Great / Good / Miss)에 따라 결과물이 결정됩니다.

### 11.2 낚시 보상
- 🐟 **생선류 (HP 회복)**: 구운 물고기(HP 20% 회복), 희귀 황금 잉어(HP 100% 회복).
- 🗑️ **잡동사니 (자원)**: 낡은 장화(소량 골드), 해초.
- 🎁 **보물 (장비/유물)**: 가끔 물에 빠진 상자를 낚아 장비나 **유물(Relic)**을 획득할 수 있습니다.
