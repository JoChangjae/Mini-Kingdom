# 📜 게임 기획서 (Game Design Document)

> **미니왕국 — 왕이 직접 뛰는 캐주얼 로그라이크 왕국 건설 게임**

---

## 1. 게임 개요

### 1.1 한 줄 소개
> 왕이 직접 던전을 탐험해 자원을 모으고, 왕국을 건설하면 다음 모험이 더 강해지는 캐주얼 로그라이크

### 1.2 기본 정보

| 항목 | 내용 |
|------|------|
| **장르** | 캐주얼 로그라이크 + 왕국 건설 |
| **플랫폼** | iOS / Android |
| **타겟 유저** | 캐주얼~미드코어 모바일 게이머 (20~40대) |
| **세션 시간** | 5~10분 (1런 기준) |
| **조작 방식** | 한 손 터치 (세로 모드) |
| **아트 스타일** | 귀여운 픽셀아트 / 도트 그래픽 |
| **시점** | 탑다운 2D |
| **과금 모델** | F2P + 선택적 광고 + 배틀패스 (에너지/티켓 제한 없는 무제한 플레이) |

### 1.3 엘리베이터 피치

*"작은 왕국의 왕인 당신은 자원이 부족합니다. 직접 던전에 뛰어들어 금화, 목재, 석재를 모아오세요! 모은 자원으로 대장간을 짓고, 마법탑을 세우면 다음 모험에서 더 강력한 장비와 마법을 쓸 수 있습니다. 왕국이 클수록 모험이 쉬워지고, 모험을 할수록 왕국이 커집니다!"*

### 1.4 레퍼런스 게임

| 게임 | 참고 요소 |
|------|-----------|
| **Archero** | 원핸드 조작, 짧은 런, 캐주얼 로그라이크 구조 |
| **Idle Kingdom Builder** | 왕국 건설 메타 루프 |
| **Slay the Spire** | 런마다 다른 빌드, 전략적 선택 |
| **하데스 (Hades)** | 런 사이 영구 성장, 스토리 진행 |
| **쿠키런: 킹덤** | 모바일 왕국 건설 UX |

## 2. 핵심 게임 루프

```
┌─────────────────────────────────────────────────┐
│                                                 │
│   🏰 왕국 화면 (허브)                            │
│   ├── 시설 건설/업그레이드                        │
│   ├── 장비 제작/강화                              │
│   ├── 왕의 칙령 선택 (일일 버프)                  │
│   ├── 주민 관리 & 방어 배치                       │
│   ├── 발견의 서 (도감) 확인                       │
│   └── 던전 선택 (일일 보너스 상태 확인)             │
│         │                                       │
│         ▼                                       │
│   ⚔️ 던전 탐험 (로그라이크 런)                     │
│   ├── 방 탐험 (자동이동 + 터치 스킬)               │
│   ├── 전투 (실시간 세미 오토 + 완벽 회피)          │
│   ├── 보상 선택 (3택 레벨업)                      │
│   ├── 이벤트 방 (상점, NPC, 보물)                 │
│   └── 보스전                                     │
│         │                                       │
│         ▼                                       │
│   📦 결과 정산                                    │
│   ├── 획득 자원 확인 (일일 1.5배 보너스 적용)       │
│   ├── 왕국 기여도 표시                            │
│   └── 다음 목표 안내                              │
│         │                                       │
│         └──────── 🏰 왕국 화면으로 ──────────────┘
│                                                 │
└─────────────────────────────────────────────────┘
```

### 2.1 세션 흐름

1. **왕국 확인** (30초) — 건설 완료 확인, 새 시설 배치, 칙령 선택
2. **던전 선택** (10초) — 난이도·보상 확인, 일일 1.5배 보너스 횟수 확인 후 출발
3. **던전 탐험** (5~8분) — 핵심 플레이
4. **결과 정산** (20초) — 보상 수령, 다음 목표 확인
5. **왕국 투자** (30초) — 자원으로 건설/업그레이드, 도감 등록

**총 세션: ~10분** → 출퇴근, 점심시간에 1~2런 가능

## 3. 세계관 & 스토리

### 3.1 배경 설정

작고 평화로운 **미니 왕국**. 어느 날 갑자기 왕국 주변에 수많은 **던전**이 나타납니다.  
던전에서 몬스터들이 쏟아져 나오지만, 던전 깊숙한 곳에는 엄청난 **자원과 보물**이 잠들어 있습니다.

왕국의 예산은 바닥나고, 용병을 고용할 돈도 없습니다.  
결국 **왕이 직접** 칼을 들고 던전에 뛰어듭니다!

### 3.2 톤 & 무드

- **유머러스하고 가벼운** 톤 (심각하지 않음)
- 왕이 직접 뛰는 코믹한 상황
- NPC들의 재치 있는 대사
- 귀엽고 둥글둥글한 캐릭터 디자인

### 3.3 주요 캐릭터

| 캐릭터 | 역할 | 특징 |
|--------|------|------|
| **왕 (플레이어)** | 주인공 | 왕관 쓴 귀여운 캐릭터, 다양한 무기 사용 |
| **재상 베리** | 튜토리얼 가이드 | 잔소리 많은 충신, 왕국 관리 조언 |
| **대장장이 해머** | 장비 제작 NPC | 무뚝뚝하지만 실력 좋은 드워프 |
| **마법사 루나** | 마법 연구 NPC | 실험 좋아하는 엉뚱한 엘프 |
| **상인 골디** | 상점 NPC | 어디서든 나타나는 수상한 상인 |

## 4. 던전 탐험 (로그라이크 파트)

### 4.1 던전 구조

```
[입구] → [일반방] → [일반방] → [이벤트방] → [일반방] → [엘리트방]
                                                          ↓
[보스방] ← [일반방] ← [휴식방] ← [상점방] ← [일반방] ← [일반방]
```

- **1개 런 = 10~15개 방**
- 방은 순차적으로 진행 (복잡한 맵 탐색 없이 직선적)
- 가끔 2갈래 길 선택지 제공 (위험한 길 vs 안전한 길)

### 4.2 방 유형

| 방 유형 | 비율 | 설명 |
|---------|------|------|
| ⚔️ 일반 전투방 | 50% | 일반 몬스터 2~5마리 처치 |
| 💀 엘리트 전투방 | 10% | 강력한 엘리트 몬스터 1마리 (좋은 보상) |
| 👑 보스방 | 런 마지막 | 보스 몬스터 처치 시 런 클리어 |
| 🛒 상점방 | 10% | 던전 내 화폐로 아이템 구매 |
| ❤️ 휴식방 | 10% | HP 회복 or 장비 강화 선택 |
| ❓ 이벤트방 | 15% | 랜덤 이벤트 (보물, 함정, NPC 등) |
| 💎 보물방 | 5% | 희귀 자원 대량 획득 |

### 4.3 전투 시스템

**세미 오토 실시간 전투** — 캐주얼하면서도 조작감 있는 전투

- **이동**: 자동 (적에게 접근)
- **기본 공격**: 자동 (일정 주기)
- **스킬**: 플레이어가 직접 터치 (2~3개 슬롯)
- **회피 및 완벽 회피**: 스와이프로 구르기. 적 공격 직전에 회피 시 '완벽 회피' 발동(0.5초 슬로모션 + 다음 공격 2배 데미지)

```
┌─────────────────────────────┐
│                             │
│      [몬스터]  [몬스터]      │
│                             │
│         [몬스터]             │
│                             │
│                             │
│          👑                  │
│        (왕 캐릭터)           │
│                             │
│  [스킬1] [스킬2] [스킬3]     │
│  ████████████░░░  HP        │
│                             │
└─────────────────────────────┘
```

### 4.4 레벨업 시스템 (런 내)

전투에서 경험치를 얻어 레벨업 시 **3가지 옵션 중 1개 선택**:

```
┌──────────────────────────────────────┐
│         ⭐ 레벨 업! ⭐                │
│                                      │
│  ┌─────────┐┌─────────┐┌─────────┐  │
│  │ 🔥      ││ 🛡️      ││ ⚡      │  │
│  │ 화염검   ││ 가시방패 ││ 번개발  │  │
│  │         ││         ││         │  │
│  │ 공격+20%││ 반사+15%││ 속도+30%│  │
│  │         ││         ││         │  │
│  └─────────┘└─────────┘└─────────┘  │
│                                      │
└──────────────────────────────────────┘
```

**업그레이드 카테고리:**
- ⚔️ **공격 계열** — 공격력, 범위, 관통, 타격 타입(물리/마법/자연) 시너지 부여
- 🛡️ **방어 계열** — 체력, 방어, 반사, 회복
- ⚡ **유틸 계열** — 이동속도, 경험치 증가, 골드 보너스
- ✨ **특수 계열** — 동료 소환, 궁극기 해금 (왕국 시설에서 해금)

### 4.5 던전 테마

| 던전 | 해금 조건 | 주요 자원 | 특수 기믹 |
|------|-----------|-----------|-----------|
| 🌲 **수풀 숲** | 시작 던전 | 목재, 약초 | 덤불에 숨은 보물 |
| ⛏️ **폐광산** | 왕국 Lv.3 | 석재, 광석 | 광차 레일 이동 |
| 🏚️ **버려진 성** | 왕국 Lv.5 | 금화, 보석 | 함정 다수 |
| 🌋 **화산 동굴** | 왕국 Lv.8 | 용암석, 희귀광물 | 용암 지형 피해 |
| 🧊 **얼음 신전** | 왕국 Lv.12 | 빙결정, 마나석 | 빙판 미끄러짐 |
| 🌀 **차원의 틈** | 왕국 Lv.15 | 랜덤 자원 | 매번 규칙 변경 |

## 5. 왕국 건설 (메타 파트)

### 5.1 왕국 화면

```
┌──────────────────────────────────┐
│  👑 미니왕국  Lv.5    💰1,250    │
│  ─────────────────────────────── │
│                                  │
│    🏠🏠  ⚒️   🏰   🔮   🏠     │
│                                  │
│    🌾  🏪  🏛️   🏠  ⛪          │
│                                  │
│    🏠  🌳  🌳  💎   🏠🏠       │
│                                  │
│  ─────────────────────────────── │
│  [건설] [탐험] [도감] [상점]      │
└──────────────────────────────────┘
```

### 5.2 시설 목록 & 던전 연계

| 시설 | 비용 | 던전 효과 | 왕국 효과 |
|------|------|-----------|-----------|
| ⚒️ **대장간** | 목재×50, 석재×30 | 시작 무기 등급 상승 | 장비 제작 해금 |
| 🔮 **마법탑** | 석재×40, 마나석×20 | 마법 스킬 슬롯 해금 | 마법 연구 가능 |
| 🌾 **농장** | 목재×30, 금화×100 | 던전 입장 시 음식 버프 | 자동 식량 생산 |
| 🏪 **시장** | 금화×200 | 던전 상점 가격 20% 할인 | 자원 교환 가능 |
| ⛪ **성당** | 석재×60, 금화×150 | 부활 1회 추가 | 주민 행복도 증가 |
| 🏛️ **왕립도서관** | 금화×300 | 레벨업 시 선택지 4개로 증가 | 발견의 서(도감) 연구 가능 |
| 🏹 **훈련소** | 목재×40, 금화×100 | 기본 공격 속도 증가 | 왕국 방어력 상승, 호위병 해금 |
| 💎 **보석 가공소** | 광석×50, 금화×200 | 보석 드롭률 증가 | 보석 세공 가능 |
| 🍺 **주점** | 목재×60 | 동료 NPC 등장 확률 증가 | 모험가 및 주민 유입 |
| 🏗️ **건축사 사무소** | 석재×80, 금화×250 | - | 동시 건설 슬롯 +1 |

### 5.3 시설 업그레이드

각 시설은 **Lv.1 → Lv.5**까지 업그레이드 가능:

```
대장간 Lv.1  →  시작 무기: 일반
대장간 Lv.2  →  시작 무기: 고급
대장간 Lv.3  →  시작 무기: 희귀  +  랜덤 보조무기 지급
대장간 Lv.4  →  시작 무기: 영웅  +  무기 특수능력 부여
대장간 Lv.5  →  시작 무기: 전설  +  세트 효과 해금
```

### 5.4 왕국 레벨

왕국 전체 레벨은 **총 시설 레벨 합산**으로 결정:

| 왕국 레벨 | 필요 시설 합 | 해금 요소 |
|-----------|-------------|-----------|
| Lv.1 | 0 | 기본 던전 (수풀 숲) |
| Lv.3 | 6 | 폐광산, 장비 제작 |
| Lv.5 | 12 | 버려진 성, 주민 시스템, 발견의 서 |
| Lv.8 | 20 | 화산 동굴, 세트 장비, 왕국 방어 이벤트 |
| Lv.10 | 28 | 일일 도전, 랭킹 |
| Lv.12 | 36 | 얼음 신전, 왕국 방문 (친구 왕국 방문) |
| Lv.15 | 50 | 차원의 틈, 엔드게임 |

## 6. 자원 시스템

### 6.1 자원 종류

| 자원 | 획득처 | 용도 |
|------|--------|------|
| 💰 **금화** | 모든 던전 | 범용 화폐, 건설/업그레이드 |
| 🪵 **목재** | 수풀 숲 | 목재 건물 건설 |
| 🪨 **석재** | 폐광산 | 석재 건물 건설 |
| ⚙️ **광석** | 폐광산+ | 장비 제작 |
| 💎 **보석** | 고급 던전 | 고급 업그레이드 |
| 🔮 **마나석** | 마법 관련 던전 | 마법 시설/연구 |
| 👑 **왕관** (프리미엄) | 과금/업적 | 프리미엄 스킨, 편의 기능 |

### 6.2 자원 밸런스 원칙

- 1런 평균 획득: 기본 자원 50~100개
- 시설 건설 비용: 3~5런 분량
- 시설 업그레이드: 5~10런 분량
- **매일 2~3런이면 주 1~2개 시설 건설 가능**

## 7. 진행 시스템 및 신규 콘텐츠

### 7.1 단기 목표 (런 내)

- 방 클리어 → 보상 획득
- 레벨업 → 빌드 강화
- 보스 도전 → 런 완료

### 7.2 중/장기 목표 (일/주/월 단위)

- 새 시설 건설 및 업그레이드
- 왕국 레벨 달성
- 장비 세트 완성 및 도감 달성 (발견의 서)
- 시즌 배틀패스 완료

### 7.3 일일 보너스 시스템 (무제한 플레이)

- **에너지나 티켓 제한 없음**, 언제든 무제한으로 플레이 가능합니다.
- **일일 보너스**: 매일 첫 5회 런에서는 획득 보상 1.5배 적용.
- 6회차부터는 일반 보상 획득.
- 매일 오전 5시에 보너스 횟수 리셋. 에너지 시스템의 답답함을 해결한 핵심 모델입니다.

### 7.4 왕의 칙령 (일일 버프)

- 매일 3가지 칙령 중 1개 선택 가능. 선택한 칙령 효과는 하루 종일 지속됩니다.
- 예시: 
  - **목재의 날**: 목재 획득량 2배
  - **전사의 날**: 공격력 +20% 증가
  - **상인의 날**: 골드 획득량 1.5배
- 일일 전략적 선택의 재미와 매일 다른 플레이 경험을 부여합니다.

### 7.5 왕국 방어 이벤트

- 주 1회(수요일) 몬스터가 왕국을 공격합니다.
- 건설한 시설과 배치한 주민 스탯에 따라 **왕국 방어력**이 자동 계산되어 결과가 정해집니다.
- 방어 성공 시 대량의 보상 제공. 실패 시에도 자원 일부 손실(수리비 등)만 발생하여 스트레스를 줄입니다.
- 왕국 건설과 업그레이드를 하는 핵심 동기부여 요소입니다.

### 7.6 발견의 서 (도감 시스템)

- 게임 내 존재하는 몬스터, 아이템, 시설, NPC들을 수집하고 기록하는 백과사전입니다.
- 도감을 채울수록 **영구 스탯 보너스** 획득 (예: 몬스터 10종 수집 시 공격력+2%).
- 플레이어의 수집 욕구를 자극하고 장기적인 목표를 제시합니다.

### 7.7 친구 왕국 방문

- 복잡한 길드 시스템 대신 도입된 가벼운 소셜 기능.
- 친구의 왕국을 방문하여 '영감' 버프를 획득합니다 (랜덤 소량 보너스).
- 하루 3회 방문 가능합니다.

## 8. 난이도 설계

### 8.1 캐주얼 유저 배려

- ❌ 영구 사망 페널티 **없음** (자원은 항상 가져감)
- ✅ 런 실패해도 **획득 자원의 70%** 유지
- ✅ **자동 전투** 옵션 (이미 클리어한 난이도)
- ✅ 쉬운 난이도는 언제든 클리어 가능하도록 밸런스
- ✅ 매 런 시작 시 **왕국 버프 자동 적용** (별도 조작 불필요)

### 8.2 코어 유저를 위한 도전

- 고난이도 던전 (왕관 보상)
- 완벽 회피 메카닉 (정확한 타이밍으로 전투 효율 극대화)
- 일일 도전 (특수 규칙 적용)
- 무한 던전 (어디까지 갈 수 있는지)
- 랭킹 시스템 (주간 순위)
